--------------------------------------------------------------------
1) Verificare lo stato dei pod:
   kubectl get pods -n {{ .Release.Namespace }}

2) Verificare i Service creati:
   kubectl get svc -n {{ .Release.Namespace }}

{{- if .Values.ingress.enabled }}

3) L'app e' raggiungibile via Ingress su:
   http://{{ .Values.ingress.host }}

   In locale (minikube/kind), va aggiunta al file /etc/hosts:
   <IP_INGRESS>  {{ .Values.ingress.host }}

   Su minikube, l'IP si ottiene con: minikube ip
{{- else }}

3) L'Ingress e' disabilitato. Per raggiungere il frontend:
   kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "habit-tracker.fullname" . }}-frontend 8080:{{ .Values.frontend.port }}
   quindi aprire http://localhost:8080
{{- end }}

{{- if or .Values.backend.autoscaling.enabled .Values.frontend.autoscaling.enabled }}

4) Verificare l'Horizontal Pod Autoscaler:
   kubectl get hpa -n {{ .Release.Namespace }}

   Se il TARGET mostra "<unknown>/...%", verificare che metrics-server
   sia installato nel cluster (su minikube: minikube addons enable metrics-server).
{{- end }}

{{- if not .Values.mongodb.auth.existingSecret }}

NOTA: il Secret MongoDB e' stato generato direttamente dal chart (existingSecret
non impostato). Se questa installazione e' andata a buon fine, significa che
sono gia' state fornite credenziali reali (es. -f values-secret.yaml) - altrimenti
i campi "required" avrebbero bloccato l'installazione prima di arrivare qui.
{{- end }}

--------------------------------------------------------------------
Per disinstallare:
  helm uninstall {{ .Release.Name }} -n {{ .Release.Namespace }}
{{- if .Values.namespace.create }}

  ATTENZIONE: namespace.create=true, quindi l'uninstall cancella ANCHE
  il Namespace "{{ .Values.namespace.name }}" e tutto cio' che contiene.
{{- else }}

  Il Namespace "{{ .Release.Namespace }}" NON viene rimosso automaticamente
  (scelta voluta, vedi commento in values.yaml). Per eliminarlo:
  kubectl delete namespace {{ .Release.Namespace }}
{{- end }}
